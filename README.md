# 侦探档案 · 罪证拼图

一个在手机上就能玩的侦探搜证推理游戏。零依赖纯前端，所有场景与人物都由 SVG 手绘生成，离线可玩。

## 玩法

1. **现场**：在每个场景里点击你觉得可疑的地方，收集线索。
2. **线索册**：随时回看已收集的物证，带「关键线索」标记的是推理必需的证据。
3. **推理**：关键证据够了才解锁。回答 3 道推理题，答错会扣分但不卡关。
4. **真相**：揭晓凶案全貌与结局剧情，给出 S / A / B / C 评级。

进度自动存在浏览器本地（localStorage）。卡住时点右上角的 `?` 可以用一次提示，会标记一处尚未搜查的地方，但每次提示扣 8 分。

## 本地运行

直接双击 `index.html` 即可；或起一个静态服务（推荐，避免个别浏览器的本地文件限制）：

```bash
python -m http.server 8123
# 然后手机与电脑连同一 WiFi，浏览器打开 http://<电脑内网IP>:8123
```

## 结构

```
index.html      页面骨架（启动页 / 案件卷宗 / 案件内三页签）
css/style.css   移动端优先样式，深色侦探风
js/art.js       SVG 素材库：70+ 道具、场景合成、人物立绘、封面插画
js/data.js      案件数据：场景布局、线索文本、推理题、真相与结局
js/game.js      游戏逻辑：搜证、线索册、推理、剧情序列、存档
```

## 技术

原生 HTML / CSS / JavaScript，无任何依赖与构建步骤。画面全部由代码绘制的 SVG 组成（场景 600×750 竖屏画布，道具在 100×100 局部坐标内绘制后缩放摆放），因此体积极小、加载瞬时、不会有任何图片版权或加载问题。
