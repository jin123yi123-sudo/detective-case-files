# 侦探档案 · 罪证拼图

一个在手机上就能玩的侦探搜证推理游戏。零依赖纯前端，离线可玩。画面双轨：有 AI 生成美术资源（WebP）就用真实图片，没有则自动回落到代码绘制的 SVG 手绘素材。

## 玩法

1. **现场**：在每个场景里点击你觉得可疑的地方，收集线索。
2. **线索册**：随时回看已收集的物证，带「关键线索」标记的是推理必需的证据。
3. **推理**：关键证据够了才解锁。回答 3 道推理题，答错会扣分但不卡关。
4. **真相**：揭晓凶案全貌与结局剧情，给出 S / A / B / C 评级。

进度自动存在浏览器本地（localStorage）。卡住时点右上角的 `?` 可以用一次提示，会标记一处尚未搜查的地方，但每次提示扣 8 分。

## 本地运行

直接双击 `index.html` 即可；或起一个静态服务（推荐，避免个别浏览器的本地文件限制）：

```bash
python -m http.server 8123
# 然后手机与电脑连同一 WiFi，浏览器打开 http://<电脑内网IP>:8123
```

## 结构

```
index.html      页面骨架（启动页 / 案件卷宗 / 案件内三页签）
css/style.css   移动端优先样式，深色侦探风
js/art.js       SVG 素材库：70+ 道具、场景合成、人物立绘、封面插画
js/data.js      案件数据：场景布局、线索文本、推理题、真相、结局、美术映射
js/game.js      游戏逻辑：搜证、线索册、推理、剧情序列、存档
assets/art/     AI 生成的美术资源（WebP，含各案 assets.json 清单）
```

## 美术资源接入

`js/data.js` 每案有一个可选的 `art` 映射块，声明图片资源后引擎即启用真实图：

- **场景底图**：`scenes.<id>.bg` 替换 SVG 场景，搜证热点改为透明脉冲圈叠加在图上，位置逐一对准图中实物；
- **特写检查**：`closeups` 把某个热点的点击流程升级为「特写大图 → 检查 → 线索卡」两段式；
- **线索卡 / 线索册**：`clueIcons` 提供物证切图，缺失自动回落 SVG；
- **对话立绘**：`faces` 按角色与情绪（thinking / angry / fear / smile…）选择立绘；
- **封面**：`coverCard` 用于案件卡片与启动页。

任何一项缺图都会自动回落到 SVG 版本，游戏永远不会因缺资源而坏掉。c2–c6 的素材包已就位，逐步在对应案件的 `art` 块中登记即可接入。

## 技术

原生 HTML / CSS / JavaScript，无任何依赖与构建步骤。SVG 层为程序化手绘：场景 600×750 竖屏画布，道具在 100×100 局部坐标内绘制后缩放摆放；图片层为 WebP 素材（首章已接入），两层共用同一坐标系，热点位置与底图精确对位。
